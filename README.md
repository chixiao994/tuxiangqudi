# 图像去底（Image Debackground）

一个用于**图像去底二值化**的 Android 应用。可批量选择输入文件夹，逐张调节二值化参数，实时预览处理效果，并将处理后的图像统一保存到输出文件夹。

---

## 功能特点

- **文件夹级处理**：选择输入文件夹，自动加载其中所有图片并按文件名排序。
- **实时预览**：调节参数时即时预览二值化效果（带 250ms 防抖）。
- **三种二值化模式**：
  - `Otsu 自动`：大津法自动计算全局阈值，适合背景与前景差异明显的图。
  - `固定阈值`：手动拖动滑块指定阈值（0–255）。
  - `自适应`：局部均值自适应阈值，适合光照不均、背景渐变的情况。
- **反色开关**：一键把黑白输出反转。
- **逐页确认**：翻页时若当前页有修改，自动保存该页结果；未修改则不触发保存。
- **跳过功能**：对不需要处理的页面直接跳过，批量保存时自动忽略。
- **重置当前页**：把当前页参数恢复默认，并清除“已修改”标记。
- **一键批量保存**：一次性处理整个输入文件夹并写入输出文件夹，结果为同名 `.png`。

## 界面布局

| 区域 | 内容 |
| --- | --- |
| 顶部第一栏 | 输入 · 输出 · 重置 · 保存 |
| 顶部第二栏 | 二值化模式 · 阈值滑块 · 阈值数值 · 反色开关 |
| 信息栏 | 当前页码 / 总页数、文件名、状态（未改 / 已修改 / 已保存 / 跳过） |
| 中间 | 图像预览区 |
| 底部栏 | 上一页 · 跳过 · 下一页 |

---

## 按钮说明

| 按钮 | 行为 |
| --- | --- |
| **输入** | 通过系统文件选择器选择输入文件夹（SAF 授权，重启后保留）。 |
| **输出** | 选择输出文件夹，处理结果以同名 `.png` 写入。 |
| **重置** | 当前页参数恢复默认，清除修改标记（不删除已写出的文件）。 |
| **保存** | 批量处理整个输入文件夹（跳过标记为“跳过”的页面）。 |
| **上一页 / 下一页** | 切换页面；当前页有修改时先自动保存该页再翻页，未修改则直接翻页。 |
| **跳过** | 不保存当前页，直接进入下一页。 |

## 构建与打包

项目已配置 **GitHub Actions**，推送到 `main` / `master` 分支后自动构建 Debug APK。

### 自动打包（推荐）

1. 把整个项目推送到 GitHub 仓库。
2. 打开仓库 **Actions** 页面，等待 `Build APK` 工作流执行完成。
3. 在该次运行的 **Artifacts** 中下载 `app-debug`，解压即可得到 APK。

也可在 Actions 页面手动触发 `workflow_dispatch`。

### 本地构建

环境要求：

- JDK 17
- Android SDK（platforms;android-34、build-tools;34.0.0）

命令：

```bash
gradle assembleDebug
